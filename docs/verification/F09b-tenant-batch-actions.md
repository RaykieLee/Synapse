## 真实浏览器流程

- 只有平台管理员显示租户复选框和批量动作；普通用户不显示复选框及“停用所选/启用所选”。
- `archived` 租户不可选择；`active` 和 `suspended` 分别进入“停用”和“启用”集合，不使用含糊的切换状态。
- 当前页全选、逐项选择和选择计数通过；筛选变化会清空选择。
- 停用确认框最多展示 5 个租户名称，并对剩余租户显示“以及其他 N 个租户”；确认说明包含 Workspace 访问会失效的提示。
- 批量更新逐项调用真实 PATCH；人为加入 500ms 网络延迟后，进度 `aria-live`、控件锁定和状态播报通过。
- 成功项自动取消选择。
- 使用 22 个真实租户、每页 10 条的三页数据验证：第 1 页选择一项后进入第 2 页，选择计数回到 0，批量按钮消失，第二页真实数据仍可见。
- 英文标题、说明、筛选工具栏、租户复选框、批量按钮、确认框和取消/确认按钮均使用英文 accessible name。
- `390 × 844` 下可选择租户、打开/取消确认框，页面无横向溢出，控制台错误数为 0。

## 部分失败与重试

- UI 的单项失败统计、失败项保留、`FORBIDDEN` 安全原因和“重试失败项”流程使用一次明确标注的网络拦截模拟制造单项 `403`；该部分不是伪装成真实后端结果。
- 真实后端的 `403` 权限边界和 `404` 不存在资源边界另行直接验证，均未泄露其他租户信息。
- 失败项保留选中状态，重试按钮可执行；重试成功后失败项清除选择。

## 限制

- 部分失败 UI 的多项统计与重试由网络拦截模拟触发，不等同于真实后端在批量请求中返回 403 的完整链路；真实 403/404 响应契约已单独验证。
- 未验证生产数据库、多进程并发批量操作、真实模型推理或邮件投递。
- 本报告只证明 F09b；不代表全项目测试通过。
