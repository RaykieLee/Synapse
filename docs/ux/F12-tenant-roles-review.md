# F12 租户角色与成员角色分配复核

状态：UX 子智能体完成只读审查；以下是本轮优化清单，不代替历史验收或当前版本的独立验收。

## 已符合的业务边界

自定义角色是租户资源，权限标识受白名单约束；内置 owner/admin/member 与 Workspace 成员角色分开。只有租户 owner/admin 可维护角色与分配，分配对象须为 active 且内置身份为 `member`。角色变更对已分配成员的有效授权会更新 `membership_version`；菜单可见性不等于 API 授权。

## 验收条件

真实 API 与浏览器验证：active owner/admin 行不能分配自定义角色并可理解原因，active member 可按现有权限分配；跨租户、撤权、禁用角色仍由服务端拒绝。刷新后筛选/页码恢复，筛选计数与空态准确；停用/删除/菜单授权说明真实影响；窄屏、键盘、读屏和中英文提示可用。静态检查与历史 F12b/F12d 报告不覆盖本轮增量。
