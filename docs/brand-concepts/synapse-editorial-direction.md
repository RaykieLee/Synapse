# Synapse 几何字标概念

设计目标：为多智能体协作平台建立清晰、现代、适合网页导航与开源仓库展示的品牌标识。

这版使用两个斜向几何形体暗示独立的 Agent 路径，在中心留下交接空间；一处薄荷绿表示任务和信息的传递。字标使用清楚的 Synapse 名称。主色为黑白，小面积薄荷绿只作焦点。
